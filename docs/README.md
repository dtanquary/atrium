# Wallpaper docs

One file per wallpaper, recording what the code can't: how each scene works, why it's built the way it is, its settings, cost, shortcuts, Dave's feedback, and ideas for next steps. Read the scene's doc before changing it, and update the doc in the same commit as the change. The app, commands and conventions are in `../CLAUDE.md`.

## Screenshots

The README's screenshots live in `docs/images` as 1600-pixel JPEGs of the wallpaper alone. All of them were rendered afresh on 2026-09-29 (except `the-moon-vs-dial-a-moon.jpg`, a check against NASA's frames) by the snapshot test at 2x Retina, which is the same pixels without switching the desktop or touching settings. For example: `SNAPSHOT_DEFAULTS="galaxy.kind=Whirlpool" SNAPSHOT_SCENE=Galaxy swift test -c release -Xswiftc -enable-testing`, with `SNAPSHOT_APPEARANCE=light|dark` for the two looks; the settings for most are in each wallpaper's doc. Random ones were picked from three or four rolls. A few need more than the test gives them:
- **Live data** comes from the app's caches in `~/Library/Caches/com.dtanquary.atrium`, since the test never fetches: seed the Sun's SDO frames and Wind's satellite tiles for today first (their URLs are in `SunImages` and `Imagery`). Earth from Orbit's night side needs a place where it's night: `SNAPSHOT_DEFAULTS="latitude=25,longitude=78"`.
- **Rain on Glass's frost** bakes off the main thread and never lands in the synchronous render test. It needs a throwaway `async` copy of the test that yields with `Task.sleep` between frames (spinning the run loop isn't enough: the test holds the main queue).
- **Moving pictures** (`<slug>.webp`, the first of each wallpaper's in the README) are the website's 12 s preview loops (`site/media.sh previews`, in the looks its `PREVIEWS` list sets) as animated WebP, 640 wide at 15 fps, through the command in `../CLAUDE.md`. Being loops, they repeat without a jump. Aurora, Deep Space Tour, Flowing Gradient, Galaxy, Lava Lamp, Nebula, Solar System Tour and Weather broke into blocks as plain WebP, so each of their frames is a keyframe (`-kmin 0 -kmax 1`). Deep Space Tour's zoom over a star field changes every pixel every frame, so it's 10 fps at q50 (`-d 100`), 5 MB; the rest are 16 KB to 3 MB. In a README table each is an `<img width="1600">`, the stills' width: GitHub splits a table's columns by its images' pixel widths, so a plain 640-wide one beside a still gets under a third of the row. The test steps a fixed 30 fps whatever the power settings, so they're always full speed.
- **Settings** screenshots (`settings-*.jpg`) are `SETTINGS_SHOT="<page>" swift test --filter settingsWindow`, saved as JPEG. The test's own defaults domain is `swiftpm-testing-helper`; clear anything a throwaway test left there.

Add or refresh one whenever a wallpaper's look changes. Settings shows one of them behind the top of each wallpaper's page: a 1200-pixel copy in `Sources/Atrium/Resources/preview-<name>.jpg`, plus `preview-<name>-light.jpg` for a Light Mode look. Refresh it with the screenshot: `sips -Z 1200 -s formatOptions 70 docs/images/nebula-hubble.jpg --out Sources/Atrium/Resources/preview-nebula.jpg`.

## Dave's direction so far

- **Favourites:** Nebula first, then Flowing Gradient. They set the bar for the rest.
- **Real over made up:** real data (the real sky, weather and ISS at his location) and colours from real sources (nebula palettes after real objects). He was delighted that Live Sky uses his actual location.
- **Variety without repetition:** a new look on each load (Nebula, Lava Lamp), and slow, seamless cycling when left running, never a hard cut. On 2026-09-26 he asked for Shuffle: Settings → General moves the desktop on to a random wallpaper every 5 minutes to every day, from a checklist of wallpapers, and picking one by hand starts the clock over. It sits beside Open at Login, which the menu already had.
- **Calm motion:** ambient only, with no mouse interaction. Anything flashy or bouncing is distracting (the ISS label was made static). Nudge speeds by small steps.
- **Colours in one family:** jewel tones like Flowing Gradient's. He called Lava Lamp's green-in-blue ugly. Nebulae shouldn't be pink every time.
- **Light and Dark Mode:** scenes that suit both should follow the system appearance (Lava Lamp, Flowing Gradient).
- **Tunable:** options go in the Settings window as data (knobs, switches, palettes), so he can tweak until it looks right. On 2026-09-26 each page got the wallpaper running live behind a glass header, trialled on Nebula first: "yeah the live preview is awesome, add it to all of them."
- **Easy on the battery:** frozen in Low Power Mode, paused when covered. On 2026-09-26 he asked to be able to override this, for demos on battery: Settings → Power has a frame-rate menu (Freeze, 15, 30, 60) for mains power, battery and Low Power Mode, and the menu bar has Full Speed on Battery. Later that day he raised the defaults from 30 and 15 fps to 60 fps plugged in and 30 fps on battery: "it seems to run fine for me on 30 on my battery but we can monitor." Watch battery life and heat at these rates.
- **Settings as a real Mac window** (2026-09-29): after a review against Apple's guidelines it stopped floating above other apps (every page has its own live preview now), joins the Dock and ⌘-Tab while open, and got search, a remembered page, the standard menus and VoiceOver fixes. macOS 26 is the minimum, and the build is stamped with the real SDK so it gets Liquid Glass.
- **Toward 1.0** (2026-09-29): a free DMG from GitHub Releases, signed ad hoc and not notarised (Gatekeeper's Open Anyway, in the README), and no App Store for now; Apple silicon only. Match the lock screen is opt-in and puts the user's wallpaper back. The app icon is "a skylight onto the cosmos" ([app-icon.md](app-icon.md)). Photos and data must be public domain or openly licensed, and credited with source and license links in About; MIT covers the code only (NOTICE).
- **Betas before 1.0** (2026-10-04): the DMG is now signed with Dave's Developer ID and notarised (`release.sh`), so there's no Open Anyway step. The first release is a beta marked Pre-release on GitHub, at whatever version is current when Dave cuts it; 1.0.0 waits until he's run a release build for a while.
- **Unfinished, hidden for 1.0** (2026-09-30): A Tree for the Year and Campfire aren't hitting the mark yet, so they're flagged `unfinished` (see their docs to revisit). Merging Game of Life and Turing Patterns into one wallpaper is on hold while Dave thinks it over; the case against was that they share no engine and few settings.
- **Workflow:** commit early and often; redeploy after each working change and tell him what to test.
- **Cut:** Zen Garden, on 2026-09-25: "so bright and sharp and not relaxing, opposite of zen." Calm means soft and dim as well as slow. Its code and doc were deleted; they're in git history before the cut.
- **Cut:** Crystals (vitamin C crystallising between polarisers), on 2026-09-27, after a smoothing pass: "just doesn't look visually appealing." The physics was right (Michel-Lévy interference colours, Maltese crosses, real growth speeds), but dimmed for calm the first-order palette read olive and the crystals as flat discs, and denser fields in second-order jewel tones didn't fix it. Real micrographs get their beauty from saturated colour and dense fine detail, which fight a calm, dim wallpaper. Physics alone doesn't make it pretty. Its code, doc and research are in git history before the cut (37f51e7).
- **Photoreal wins:** Galaxy only clicked once it was compared side by side with Hubble photos: colours sampled from them, soft edges, a bright disc rather than shapes on black, and an asinh stretch. The Fish Tank and Weather got the same treatment: research agents, real photo cut-outs where they beat procedural (fish, corals, hills, cumulus), physics where it beats photos (Weather's sky), and renders compared with reference photos.
- **Next:** iterate through each wallpaper to improve it, cut the weak ones and add new ones.
